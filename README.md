# SullivanServer

Community website for the Sullivan Minecraft server network.

**[Visit the website](https://sullivanserver.vercel.app/)**

## About

SullivanServer is a simple static website that introduces the community's Minecraft servers, provides server information and updates, and helps players find the right place to join.

## Built With

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
.
├── index.html      # Main website
├── server1.html    # Sullivan SMP
├── server2.html    # Sullivan BMC
├── server3.html    # Nightfall RPG
├── server4.html    # Deceased SMP
├── develop.html    # Community history and world archives
├── style.css       # Shared website styles
└──  script.js       # Shared interactions
```
